[Linux] 基础知识

目录功能

  • /tmp: 临时文件夹, 其内的内容会定期清理
  • /opt: 用于安装第三方软件
  • /home: 普通用户的家目录
  • /root: root用户的家目录
  • /usr: 用户程序/系统软件的资源目录
  • /etc: 系统全局配置文件
    • /etc/profile.d/xxx.sh: 当 用户登录 或 打开新的 shell 时，系统会自动执行该目录下的所有 .sh 脚本

基础指令

1. chmod - 修改文件/目录的权限

Linux 里每个文件都有三组权限：

  • 所有者（user）
  • 所属组（group）
  • 其他用户（others）

权限数字:

数字 含义
7 可读、可写、可执行
5 可读、可执行

常用 755

2. source - 执行脚本

在当前 shell 中执行另一个脚本文件的内容

3. export - 环境变量

  • 用 : 来分隔环境变量, 从前往后查询
  • 用 $ 来获取环境变量的值

export PATH=/opt/conda/bin:$PATH: 在环境变量前面加入 /opt/conda/bin

4. alias - 命令的临时别名

alias nv='nvidia-smi'

5. rsync - 有进度条的复制

rsync -ah --info=progress2 /media/aiic/Elements/ysm /data/SQ/
