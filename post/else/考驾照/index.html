考驾照

1. 依法扣留车辆

未携带机动车登记证书 不属于依法扣留车辆

  • 确保: 驾驶证, 行驶证, 交强险
  • 登记证书没关系

2. 校车

  • 校车同方向只有1条车道，后方车辆停车等待
  • 校车同方向有2条以上车道，校车后方及相邻车道车辆要停车等待 (其他车道车辆可以减速通过)

3. 车型代号

客车类:

  • A1: 大型客车(大巴) [四个窗一个门] (22-63岁)
  • A2: 重型牵引挂车
  • A3: 城市公交车

客货中型:

  • B1: 中型客车(中巴) (20-63岁)
  • B2: 大型货车 (20-63岁)

小型民用汽车:

  • C1: 小型汽车 (18-∞岁)
  • C2: 小型自动挡汽车 (18-∞岁) (length<=6m, people<=9)
  • C3: 低速载货汽车
  • C4: 三轮汽车
  • C5: 残疾人专用小型自动挡载客汽车
  • C6: 轻型牵引挂车 (20-70岁)

摩托车类:

  • D: 普通三轮摩托车
  • E: 普通二轮摩托车
  • F: 轻便摩托车

特种工程机械 / 电车:

  • M: 轮式专用机械车
  • N: 无轨电车
  • P: 有轨电车

4. 三年以下

  • 死亡一人或者重伤三人以上，负事故全部或者主要责任的
  • 死亡三人以上，负事故同等责任的
  • 造成公共财产或者他人财产直接损失，负事故全部或者主要责任，无能力赔偿数额在三十万元以上的

5. 科目考试上限

简记为3年5次

  • 科二5次
  • 科三5次

6. 上下坡

上坡: 减档, 踩加速踏板

下坡: 不准空档或熄火

  • 如果熄火, 车辆就不能使用发动机制动了
  • 如果连续只使用行车制动器, 则行车制动器温度过高时制动效果急剧下降
  • 故而最好是行车制动器+发动机制动, 故而要低速档行驶

7. 车灯

夜间事故打灯:

  • 危险报警闪光灯: 警示周边车辆避让 (雨雪天临时停车也要开)
  • 示廊灯: 点亮车辆前后轮廓
  • 后位灯: 显示车辆尾部位置

为了让其他车辆发现本车: (光线不良)

  • 前照灯(车头大灯，分近光、远光)
  • 示廊灯: 点亮车辆前后轮廓

低能见度天气:

  • 雾灯

没有交通信号灯的路口:

  • 交替使用远近光灯

能开远光灯的情况: 夜间郊外无路灯、无对向车辆道路

  • 当快到路口30-100m时, 关闭远光灯
  • 会车在150m以外就要改近光灯
  • 与非机动车会车时, 要用近光灯

8. 道路无车道划分

  • 车辆在中间通行
  • 行人和非机动在两侧

14. 同向双车道

  • 左侧快速
  • 右侧慢速
  • 在慢速车道超车时可以借用快速车道

15. 交通事故管理区

事故发生地的前方!!!

  • 预警区(黄色标志): 500-1000m [有四位数]
  • 警戒区(红色标志): 200-500m

16. 不可超车

  • 交叉路口
  • 窄桥
  • 隧道
  • 匝道, 加速车道, 减速车道

17. 高速故障

  • 车移到应急道
  • 人到路肩/护栏外

18. 掉头

掉头是向左掉头, 应该提前开启左转向灯

城3公4, 城5公7, 3特找30 (特殊路段, 特殊天气, 特殊情况 -> 30km/h)

无中线:

  • 城市道路: 30km/h
  • (乡村)公路: 40km/h

有中线:

  • 城市道路: 50km/h
  • (乡村)公路: 70km/h

高速: 60-120km/h

  • 两道: 120-100-60
  • 三道: 120-110-90-60

20. 标线

虚线: 指示标线 实线: 禁止标线

黄色: 分隔对向车流 白色: 分隔同向车流

21. 不得超车

  • 复杂路段(交叉路口, 隧道, 人行横道, 铁路道口, 交通流量大的路段)
  • 特种车
  • 前车向左
  • 有来车

22. 罚款

绝大部分是200罚款(所有权转让)

  • 拼装, 报废, 超速50%, 把车交给无证驾驶的: 200<罚款<2000 + 吊销驾照

23. 261, 145, 52离

261, 145, 52离

  • 261: 能见度200, 速度60, 车距100
  • 145: 能见度100, 速度40, 车距50
  • 52离: 能见度50, 速度20, 尽快驶离高速

24. ABS系统 (汽车防抱死制动系统)

避免在紧急制动时方向失控及车轮侧滑，使车轮在刹车时不被锁死，保持前轮转向能力 -> 防止车轮抱死

紧急制动: 用力踏制动踏板 -> 但如果紧急制动的时候同时转向, 则仍有可能发生侧滑

但是冰雪路面会增大制动距离

27. 警告标志放置

28. 扣钱

20-200元:

  • 有新证, 用原证
  • 实习期单独上高速
  • 应撤未撤导致堵塞
  • 信息变更30天未备案 (电话, 从业单位)
  • 没带驾驶证行驶证

200-2000元:

  • 驾驶拼装的
  • 驾驶报废的
  • 驾驶50%超速的
  • 把车交给无证驾驶的
  • 故意损害, 移动, 涂改交通设施
  • 非法拦截不听劝
  • 不构成犯罪的逃逸

200-500元:

  • 逾期不审验 250
  • 身体不适/疲劳驾驶 250
  • 以隐瞒欺骗的手段补驾驶证 250
  • 补充: 扣教练的 250

1000-2000元: (四位数长记性)

  • 初次饮酒
  • 再次饮酒

2000-5000元:

  • 伪造, 变造 (看到"伪"找最大)

29. 扣分

高速:

  • 逆行: 12
  • 违停: 9
  • 占用应急车道: 6
  • 低速: 3

1分: 灯禁掉会检安

  • 违规用灯
  • 违反禁止标志, 违反禁止标线
  • 普通道路-掉头/倒车
  • 普通道路-不按规定会车
  • 不年检
  • 不系安全带
  • 补充: 长宽高超限, 擅自改变车身结构

霸总开着豪车年检，因为他已经忘了一年。晚上偶遇了白月光。只是他开着远光灯，和白月光会车时，闪瞎了白月光钛合金双眼。白月光没有系好安全带，霸总一眼就瞧上了这个桀骜不驯的白月光，虽然旁边有禁止掉头的标志，霸总还是违反禁令标志，决定倒车掉头去追求人家。

3分: 让道超装电低警

  • 各种不避让 (不让校车) (不让行人)
  • 不按规定车道 (借道超车)
  • 不按规定超车
  • 没按规定安装号牌
  • 打电话
  • 高速路低于最低速
  • 未按规定设置警告标志 (50-100m, 150m)

霸总刚刚买完豪华货车，觉得很帅，就把号码牌牌装到了车顶。连续开了4小时，快要睡着了，结果白月光来电要和霸总分手。霸总伤心欲绝，一边打电话，一边用最慢速度开在高速上，还占用别的车道。为了赶回去挽回白月光的心。下了高速后，随意超车，还逆行，遇到小孩放学也不让。最后，意外发生，霸总的车抛锚，霸总没有在车子后门放警告牌，就继续跟白月光打电话，求白月光不要分手

6分: 轻信占扣

  • 轻伤的逃逸
  • 不按信号灯通行 (闯红灯)
  • 占用应急车道
  • 扣留驾驶证后, 还驾驶 (刚好一半)
  • 补充: 未悬挂警示标志

霸总和白月光和好之后，自己的驾照就被暂扣了。下班的时候听到白月光和男二上车了。霸总没有驾驶证的情况下，依旧开车去追白月光。高速上堵车，为了能够追上白月光霸总就占用了应急车道，还闯红灯，追到之后，看到男二下车了，就追上去用车轻微擦伤了男二，带着白月光走了

9分: 违停不符没号牌

  • 高速-违停
  • 准驾车型不符 (包括: 未取得校车资格)
  • 没号牌/遮挡号牌

白月光和霸总和好之后，就想度蜜月。霸总没有校车驾驶证，他也不管，开着校车，连续开了4小时没休息，带着一群朋友翻山越岭去度假。完全没有注意到车牌号码已经被泥水遮挡住。在开到高速的时候，白月光说看到了很好看的风景。霸总就把车停在了高速上，给白月光拍照片

12分: 酒伪亡反谋利益

  • 酒驾
  • 伪造号牌, 使用其他号牌/行驶证
  • 轻伤以上(or死亡)的逃逸
  • 高速路-逆向(反)
  • 代替他人罚分
  • 补充; 高速-超速50%

霸总和白月光分手之后，喝了个大醉，为了避免他爹追自己，弄了个假的汽车牌照，在高速上倒车逆行，把路人撞成重伤，还连夜逃跑

高速: 倒车12分, 掉头12分, 逆行12分 普通道路: 倒车1分, 掉头1分, 逆行3分

30. 一三五十终身不得报考

考试中一年, 考试后三年

假一, 吊二, 撤三, 骗三, 代三, 毒三, 醉五, 罪五, 证十, 逃终身

假一: 虚假材料, 一年不得报考 吊二: 吊销驾照, 二年不得报考 撤三: 撤销驾照, 三年不得报考 骗三: 欺骗贿赂, 三年不得报考 代三: 代替考试, 三年不得报考 毒三: 吸毒行驶, 三年不得报考 醉五: 醉驾吊销, 五年不得报考 罪五: 犯罪吊销, 五年不得报考 证十: 无证驾驶, 十年不得报考 (补充: 醉驾驾驶运营车也是10年) 逃终生: 肇事逃逸, 终生不得报考 (补充: 醉驾导致犯罪也是终生)

审验教育/学习考试 虚假材料: 500元 审验教育/学习考试 弄虚作假: 1000元 审验教育/学习考试 贿赂代替: 2000元 审验教育/学习考试 组织他人: 3倍 (最高2万)

买卖分: 5-10万

31. 口五站三

口五站三

口五: “口”, 50m (交叉路口, 铁路道口, 弯道, 隧道, 窄路: 50m不可停车) 站三: “站”, 30m (公交站, 加油站, 消防站: 30m不可停车) 剩下: 全选150m (没有150m就选最大的)

32. 学法减分

公益111, 现场112, 网上331

公益111: 满1小时为1次, 减1分 现场112, 满1小时为1次, 减2分 网上331: 3日累计30分钟, 减1分

一个学习周期内最多减6分

实习期and2次以上累计12分and3周期内的酒驾, 不能通过学习减分

33. 酒驾

20mg/100ml<酒精含量<80mg/100ml

初次:

  • 6个月驾驶证
  • 1000<罚款<2000

再次:

  • 吊销驾驶证
  • 1000<罚款<2000
  • 10日拘留

34. 醉驾

酒精含量>80mg/100ml

  • 吊销驾驶证
  • 追究刑事责任 (但是也可能没有触发刑事案件, 所以不一定要有期徒刑)
  • 五年内不得考驾驶证

35. 事故责任

未逃3以下, 死逃3-7, 逃死7以上

  • 3年以下: 重伤, 死亡, 重大财产损失
  • 3年-7年: 死亡且逃逸
  • 7年以上: 逃逸后致人死亡

36. 超员

小车: 7下36, 7上69

7座以下的车超员20%-50%: 3分 7座以下的车超员50%-100%: 6分

7座以上的车超员20%-50%: 6分 7座以上的车超员50%-100%: 9分

校车, 客车: 6-12

超员20%以下: 6分 超员20%以上: 12分

100%以上都是扣12分

37. 超速 (过半则翻倍)

小车: 小: 普36, 高612

普通公路超速20%-50%: 3分 普通公路超速50%以上: 6分

高速公路超速20%-50%: 6分 高速公路超速50%以上: 12分

校车/中型客车货车: 大: 普169, 高612

普通公路超速10%-20%: 1分 普通公路超速20%-50%: 6分 普通公路超速50%以上: 9分

高速公路超速20%以下: 6分 高速公路超速20%以上: 12分

38. 货车超载

货车超载136

  • 1<30%<3<50%<6

39. 编号

国道标志: G: guo 省道标志: S: shen 县道标志: X: xian 乡道标志: Y: 顺延

40. 满分学习

一个记分周期内记12分 -> 小车学1周, 大车学1月

  • 满12分 / 1-2年内未换证 -> 考科一
  • 满12-24分 / 一个周期内2次累计12分 -> 考科一科三
  • 满24-36分 -> 考科一科二科三

每增加12分, 校车加7天

  • 现场2天
  • 网络3天
  • 自主2天

41. 满90变30审30

满90变30审30

满90: 驾驶证有效期满时，需提前90天申请换证 变30: 信息变更, 在30天内向核发地车管所申请信息变更和换证 审30: 发生事故后, 在记分周期结束后30日内接受审验

last. Special

科二: 场地驾驶技能考试

科三: 道路驾驶技能考试

  1. 从匝道进入高速, 应该开启左转向灯

  2. 交通肇事罪: 三个为**“未”**的不选

  3. 看到"拘役"就选对

  4. 车有问题就扣车, 而不是扣人 (2证2标1号牌: 驾驶证行驶证/检验合格标志保险标志/机动车号牌) -> 驾驶证是归属于人的, 行驶证是归属于车的

  5. 转弯让直行, 右转让左转, 右方道路来车先行 -> 直行>左转>右转

  6. 新手一年内不能单独上高速, 若要上高速需要三年以上老司机陪同

  7. 一停, 二看, 三通过

  8. 飙车: 拘役+罚款

  9. 三角形黄色是警告(代表小心), 正方形蓝色是指示(代表应当)

  10. 发生重大交通事件, 终身不能报考

  11. 夜间驾车, 通过人行横道/没有信号灯的交叉口/超车时, 交替使用远近灯光

  12. 雨天路面湿滑, 紧急制动/急刹车容易翻车, 应该用发动机制动减速

  13. 高速红进绿出, 一个杠100m

  14. 踏板: 离合/制动/加速

  15. 运营车每5年检验一次, 非运营车每10年检验一次

  16. 拿到驾照后, 申请准驾车型: 轻牵1中牵2重牵3 (年)

  17. 争议3天, 调解10天, 惩罚15天, 补发换15

  18. 初次申领的在住所地车管所, 登记证书, 行驶证, 号牌: 都是找登记地车管所, 之后都在核发地车管所 [变更信息30天, 兵役/出国的延期] (如果居住在核发地以外的地方, 则向居住地车管所)

  19. 驾驶证的补发补领, 任何车管所都可以

  20. 同类增驾无实习期

  21. 学习期间只罚教练

  22. 无偏移则不转向, 减速紧握方向盘

    • 侧滑同向修正

  23. 山路会车: 外侧车辆先行(不靠山体的车辆) (因为内侧车辆更安全, 应该让行)

  24. 上下坡会车: 上坡车辆先行 (因为上坡阻力大/起步难/易溜车, 所以下坡要让上坡)

  25. 逆时针绕车检查

  26. 机动车如果是静止的, 可能完全无责; 但如果不是静止的, 最低也要承担不超过10%的责任

  27. 审验验人, 检验验车

  28. 双白虚线: 减速让行 双白实线: 停车让行

  29. 蓝色: 免费停车位 黄色: 专属停车位 白色: 收费停车位

  30. 有刀叉的才是服务区

  31. 进入环岛不用开灯, 离开环岛需要开右转向灯

  32. 湿滑路面发现车辆失去控制时, 要立即松开制动踏板

    • 过度制动会更加打滑
    • 猛踩刹车会导致车轮锁死

  33. 大中客车, 牵引挂车不能初次申领

  34. 车辆涉水后, 应该间断轻踏制动踏板, 给刹车片一些温度来蒸发一些水, 恢复制动效果

  35. 满期换发要审验驾驶人 (6年->10年->长期)

  36. 开车4小时, 休息20分钟 -> 否则疲劳驾驶

  37. 准驾车型不同, 则条件不同

  38. 红色是最高速度, 蓝色是最低速度, 黄色是建议速度, 灰黑色是解除限速

  39. 70周岁/大中客货司机 -> 1年体检1次

  40. 车不合格, 交警会扣车, 而不是扣证

  41. 右转不受圆灯限制

  42. 雾天: 选项内如果没有雾灯, 则选危险报警闪光灯

  43. 学习驾驶证明的有效期是3年, 5次科二和5次科三

  44. 货车上高速最大49吨

  45. 高速禁止学车(不能有教练车)

  46. 高速邻近出口1km时不要再超车了

  47. 危险物品拜溜: 高速80km/h, 普路60km/h

  48. 车辆后方…m, 事故现场前方…m

  49. 交叉路口, 如果堵车, 哪怕绿灯也不能驶入, 以防更堵
