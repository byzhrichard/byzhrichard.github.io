概述

  • 应用层 = 信的内容
  • 传输层 = 挂号信:不丢不乱
  • 网络层 = 规划城市之间的路线
  • 数据链路层 = 每一段路上的交接
  • 物理层 = 真正跑在路上的卡车

internet: 泛指互联网 Internet: 专指全球最大的互联网(使用TCP/IP)

边缘部分: 主机(手机/电脑/服务器, 客户使用) 核心部分: 网络+路由器 -> 为边缘提供连通和交换服务

边缘部分的两种通信方式:

  • 客户-服务器 C/S (client/server)
  • 对等方式 P2P (peer to peer) [e.g. BT下载]

不用 电路交换 和 报文交换, 而是 分组交换

  • 不独占线路; 分组小, 时延短
  • 每个分组都要带首部; 要在路由器里排队

计算机网络的分类:

网络速率:

带宽: (bit/s)

吞吐量: 是实际的带宽, 往往比带宽小

时延:

  • 发送时延: 把一个分组的所有byte推上链路所需的时间 发送时延 = 数据长度(bit) / 发送速率(bit/s)

    • 提高带宽只能减少发送时延

  • 传播时延: 电磁波在信道里跑完这段距离的时间 传播时延 = 信道长度(m) / 传播速率(m/s)

    • 传播时延只和距离和介质有关, 光纤中约5us/km=2x10^8^m/s

  • 处理时延

  • 排队时延

总时延=发送+传播+处理+排队

时延带宽积: 链路上正在传输的bit数, 也就是管道的容积 时延带宽积 = 传播时延 x 带宽

往返时间 RTT:

信道利用率: (信道利用率越高, 排队时延越大)

当前排队时延D = 空闲时排队时延D0 / (1-利用率U)

协议: 同一层的通信双方要遵守的规则(协议是水平的, 对等层之间的规则)

  • OSI七层参考模型 -> 理论完整, 但过于复杂
  • TCP/IP (网络接口层/网际层/传输层/应用层) -> great

教学上分五层: 物理层/网络接口层/网际层/传输层/应用层

  • 应用层: 直接为应用进程服务 e.g. HTTP, DNS, SMTP
  • 传输层: 进程 <-> 进程 (端到端) e.g. TCP, UDP
  • 网络层: 主机 <-> 主机 (跨越多个路由器) e.g. IP, 路由选择
  • 数据链路层: 在一段链路上, 以帧为单位传输数据 e.g. PPP, 以太网
  • 物理层: 在介质上透明的传输比特流 e.g. 电压, 光, 电磁波

每一层传输的数据单元都有专属的名字

  • 应用层: 报文message
  • 传输层: 报文段segment / 用户数据报
  • 网络层: IP数据报 / 分组package
  • 数据链路层: 帧frame
  • 物理层: 比特bit

TCP/IP体系是沙漏形的:

  • 可以有各种应用和网络, 但中间网络层都经过IP这一个协议
  • 网络层向上只提供无连接, 可靠性交给端系统的TCP来保证

物理层

传输介质:

  • 导引型
    • 双绞线
    • 同轴电缆: 带宽大, 损耗小, 抗干扰
      • 多模光纤
      • 单模光纤
    • 光线
  • 非导引型
    • 无线电/微波/红外

通信方式:

  • 单工 (e.g. 广播电台)
  • 半双工: 不能同时 (e.g. 对讲机)
  • 全双工: 可以同时 (e.g. 打电话)

码元: 一个固定时长的信号波形, 代表一个离散的数值

波特率: 每秒传多少个码元 (如果码元有V种状态, 那么码元就能携带 $\log_2(V)$ 个比特)

比特率: 每秒传多少个比特 比特率 = 波特率 * log2(V)

奈奎斯特定理: 在理想信道中, 极限码元传输速率是2W波特 (W: 信道带宽, 单位Hz) 极限数据率 = 2W * log2(V)

-> 增大V来让每个码元携带更多比特, 可提高极限数据率

香农定理: 在有噪声的信道中, 极限数据率 = W * log2(1+S/N), 其中信噪比 用比值表示 (S/N: 信噪比, 有分贝表示[dB]和比值表示[单位1]) (分贝表示=10*log10(比值表示))

-> 给出的是绝对上限, 再怎么编码V也超不过上限

两个定理的数据同时给出时, 最大数据率取二者中较小的那个

数字信号编码:

  • 不归零编码NRZ (高电平表示1, 低电平表示0) -> 但连续出现很多1或0时, 接收方无法提取时钟
  • 曼彻斯特编码 (在每一位的中间都有一次跳变, 中间向下跳表示1, 中间向上跳表示0) -> 跳变本身就可以当时钟用 -> 传统以太网的选择
  • 差分曼彻斯特编码 (在每一位的中间都有一次跳变, 但只用来同步; 开始的边界有跳变表示0, 开始的边界无跳变表示1)

曼彻斯特编码每个比特bit要用两个码元, 所以比特率=码元速率/2, 编码效率只有50%

数字信号->模拟信号编码:

  • 调幅ASK: 用不同的振幅表示0和1
  • 调频FSK: 用不同的频率表示0和1
  • 调相PSK: 用不同的相位表示0和1

正交振幅调制QAM: 把振幅和相位结合起来 (e.g. 16-QAM的一个码元携带4比特)

物理层设备:

  • 中继器: 整形, 放大, 延长距离
  • 集线器: 多端口的中继器 (只认识比特, 不认识帧)
